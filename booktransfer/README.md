# Book Transfer — перенос текста в книгу (Fabric, Minecraft 26.2)

Клиентский мод: открываешь книгу с пером → слева кнопка **«Перенос текста»** →
вставляешь текст → мод сам раскладывает его по страницам.

## Что умеет
- Разбивка по страницам ровно по правилам книги: 114 px ширины, 14 строк, до 1024 символов,
  до 100 страниц. Слова не разрываются (кроме слов длиннее строки), пробелы в начале страницы убираются.
- Предпросмотр каждой страницы на «бумаге» справа.
- Форматирование, которое продолжается на следующей странице:
  | Что | Markdown | Код |
  |---|---|---|
  | Жирный | `**текст**` | `&l` |
  | Курсив | `*текст*` | `&o` |
  | Зачёркнутый | `~~текст~~` | `&m` |
  | Подчёркнутый | `__текст__` | `&n` |
  | Меняющийся | `\|\|текст\|\|` | `&k` |
  | Цвет | — | `&0`…`&f` |
  | Сброс | — | `&r` |

  `&&` — сам знак &, `\*` — звёздочка без курсива. Строка `---` — новая страница.
  Кнопки B / I / S / U / K / R и цветные квадраты вставляют разметку в позицию курсора
  (или оборачивают выделенный текст).
- **Перевёрнутый текст** (кнопка «Перевёрнутый» — весь текст, или тег `[flip]…[/flip]` — кусок).
  Свою таблицу можно добавить в `config/booktransfer-flip.txt` (строки вида `а=ɐ`).
- **Эффекты** (кнопка ★ или теги):
  `[rainbow]` радуга, `[wide]` Ｗｉｄｅ, `[small]` ᴄᴀᴘɪᴛᴀʟ, `[sup]` надстрочный x², `[mirror]` зеркало,
  `[center]` по центру. Закрываются `[/rainbow]` и т.д. Работают и русские имена: `[радуга]`, `[центр]`…
- **Заголовки и оглавление**: строка `# Глава 1` — жирный заголовок по центру, с новой страницы.
  В настройках (⚙ или Mod Menu): оглавление в начале книги и номера страниц внизу.
- **Шаблоны стилей**: в окне ★ задаёшь имя и коды (например `важно` = `&c&l`),
  потом пишешь `[важно]текст[/]`.
- **Импорт .txt**: кнопка «Файл» или просто перетащи файл в окно игры (UTF-8 и Windows-1251).
- **Многотомник**: если текст больше 100 страниц, продолжение пишется в пустые книги с пером
  на хотбаре; при подписи книги получают названия «Название (1)», «Название (2)»…
  Если книг не хватило — остаток копируется и подставится в следующую книгу.
- Режимы «заменить» / «дописать» в конец книги, можно сразу подписать книгу.
- Настройки сохраняются в `config/booktransfer.json`.

## Установка
1. Fabric Loader 0.19.5+ и Fabric API для 26.2. Mod Menu — по желанию.
2. Скачать jar: GitHub → вкладка **Actions** → последний запуск «Build Book Transfer mod» →
   артефакт **booktransfer-mod** (внутри `booktransfer-1.1.0.jar`).
3. Положить jar в папку `mods`.

Работает и на серверах: коды форматирования в книгах ванильный сервер не вырезает
(плагины на конкретном сервере могут).

## Сборка
Java 25: `./gradlew build` → `build/libs/`.
